# 🤖 سیستم تشخیص اشیاء با هوش مصنوعی (YOLOv8 + FastAPI + Docker)

این پروژه یک سرویس RESTful API قدرتمند، سریع و مقیاس‌پذیر برای تشخیص اشیاء در تصاویر است. این سیستم با استفاده از مدل پیشرفته **YOLOv8** آموزش دیده و در قالب یک **میکروسرویس** با **FastAPI** پیاده‌سازی شده است. همچنین برای استقرار آسان و بدون دردسر روی هر سروری، کاملاً با **Docker** کانتینرایز شده است.

## ✨ ویژگی‌ها
- 🎯 **تشخیص دقیق اشیاء:** استفاده از مدل YOLOv8 برای شناسایی ۸۰ کلاس شیء رایج (انسان، خودرو، حیوانات و...).
- ⚡ **سرعت بالا:** ارائه سرویس از طریق FastAPI (یکی از سریع‌ترین فریم‌ورک‌های پایتون).
- 🐳 **استقرار آسان:** بسته‌بندی شده در Docker برای اجرا روی هر سیستم‌عاملی بدون مشکل وابستگی‌ها.
- 🖥️ **رابط کاربری دسکتاپ:** دارای نسخه دسکتاپ ساخته شده با PyQt5.
- 📖 **مستندات تعاملی:** دارای Swagger UI خودکار برای تست آسان API.

## 🛠️ تکنولوژی‌های استفاده شده
- **Python 3.11**
- **YOLOv8** (Ultralytics)
- **FastAPI** & **Uvicorn**
- **Docker**
- **PyTorch** & **OpenCV**
- **PyQt5** (برای نسخه دسکتاپ)
